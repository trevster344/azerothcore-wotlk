    How to Play

    Follow these steps to get in-game.

    1. Download the game client

      Grab the client from unlimited-wow.com/page/connect.

    2. Set your realmlist

      Open realmlist.wtf in your game folder and set it to the server IP:

      set realmlist 26.175.239.74
    3. Launch the game directly

      Run Wow.exe instead of the launcher — the launcher can overwrite realmlist.wtf, which would make you repeat step 2.
